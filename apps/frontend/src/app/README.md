# Frontend App Boundary

## Purpose

This directory owns the frontend application shell and provider boundaries.

Stage 2B may include provider setup for scaffold validation, but it does not include Auth routing, protected routes, session bootstrap, or domain feature behavior.

## Current Boundaries

- React Router provider boundary exists for future route ownership.
- TanStack Query provider boundary exists for future server state ownership.
- Auth-specific behavior remains outside this directory during Stage 2B.
