# Auth Feature Boundary

## Purpose

This directory is reserved for the Auth frontend feature implementation.

Stage 2B frontend scaffold does not implement Auth UI or Auth API behavior.

## Allowed In This Stage

- Boundary documentation.
- References to Auth domain and API contract artifacts.

## Forbidden In This Stage

- Login page.
- Login form.
- Auth API client.
- Auth hooks.
- Protected route.
- Session bootstrap.
- Cookie/session handling.
- Auth behavior tests.

## Source Of Truth

- `.ai/domains/auth/auth-api-contract.md`
- `.ai/domains/auth/auth-domain-contract.md`
