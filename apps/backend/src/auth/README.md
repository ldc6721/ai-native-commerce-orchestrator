# Auth Boundary

## Purpose

This directory is reserved for the Auth domain backend implementation.

Stage 2B backend scaffold does not implement Auth behavior.

## Allowed In This Stage

- Boundary documentation.
- References to Auth domain and API contract artifacts.

## Forbidden In This Stage

- Auth module.
- Auth controller.
- Auth service.
- DTOs.
- Guards or middleware.
- Login/logout/current-user/session endpoint implementation.
- Cookie handling.
- Redis session store implementation.
- Password hashing.

- `.ai/domains/auth/auth-domain-contract.md`
